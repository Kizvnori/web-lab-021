# เปรม นมสด (Prem Nomsod) - Landing Page 🥛🍞

Landing Page สำหรับร้าน **"เปรม นมสด"** ร้านนมสด ขนมปังปิ้งเตาร้อน และของทานเล่นยามค่ำคืน

![เปรม นมสด](./logo.png)

## 📌 จุดเด่นของหน้าเว็บ
- **Responsive Web Design**: รองรับการแสดงผลทั้งบน Desktop, Tablet และ Smartphone
- **ภาพจริงจากทางร้าน**: รวบรวมเมนูซิกเนเจอร์ เช่น นมสดร้อนแก้วเคลือบวินเทจ, นมชมพูในโหลแก้ว, ปังปิ้งช็อกโกแลต, ปังเย็นภูเขาไฟ, นักเก็ต และเฟรนช์ฟรายส์
- **Interactive Menu Filter**: กรองหมวดหมู่เมนูได้ทันที (เครื่องดื่ม, ขนมปังปิ้ง, ของทานเล่น)
- **Interactive Google Maps**: แผนที่ตั้งร้านพร้อมปุ่มนำทาง
- **Facebook Fanpage Integration**: ปุ่มและกล่องการ์ดเชื่อมต่อไปยังเพจร้านโดยตรง

## 🛠️ เทคโนโลยีที่ใช้
- **HTML5** & **Tailwind CSS** (via CDN)
- **Google Fonts (Kanit)**
- **Lucide Icons**
- **JavaScript (Vanilla)**

## 🚀 การเผยแพร่ผ่าน GitHub Pages
1. ไปที่แท็บ **Settings** ของ Repository บน GitHub
2. เลือกเมนู **Pages** ทางแถบซ้าย
3. ใต้หัวข้อ **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอสักครู่ GitHub Pages จะสร้าง URL ให้สามารถเข้าชมหน้าเว็บออนไลน์ได้ฟรีทันที!
